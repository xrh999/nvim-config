# Set up

## Installing Miscellaneous programs
tree-sitter-cli, yazi, and ripgrep are required to be installed

Here's the command for MacOS brew users:
`brew install tree-sitter-cli yazi rg`

## Install LSPs
All the LSPs used in the config can be found in the servers table in lua/plugins.lua

Here's a MasonInstall command for every LSP used in this config`:MasonInstall basedpyright bash-language-server clangd css-lsp html-lsp json-lsp lua-language-server marksman typescript-language-server tailwindcss-language-server`
